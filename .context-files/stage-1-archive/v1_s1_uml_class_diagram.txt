' DESIGN NOTES
' ==========================================

note right of GameController
  GAME FLOW

  1. Process customer arrivals.
  2. Collect and validate Waiter choice.
  3. Execute Waiter action immediately.
  4. Collect and validate Chef choice.
  5. Execute Chef action immediately.
  6. Run automatic end-of-turn updates.

  Invalid choices do not modify state.
end note

note right of TurnProcessor
  AUTOMATIC SIMULATION

  Handles:
  - Eating progression
  - Payment eligibility
  - Automatic cashier payment
  - Satisfaction reduction
  - Customer abandonment

  Keeps GameController focused
  on player actions and sequencing.
end note

note right of GameState
  GAME RULES

  18 turns total.
  Arrivals on turns:
  1, 4, 7, 10, 13, 16.

  Victory checked after turn 18:
  Paid >= 4
  Revenue >= 4500 cents
  Average paid satisfaction >= 60

  If paidCount = 0:
  Average displays N/A.

  Collection getters should return
  read-only views or defensive copies.
end note

note right of Customer
  CUSTOMER LIFECYCLE

  Initial satisfaction = 100.
  Waiting loss = 8 per turn.
  Minimum = 0.

  assignOrder() updates order.
  onServed() records servedTurn.
  finishEating() records payment readiness.
  onPaid() updates customer status.

  Future Stage 2 subclasses can
  override lifecycle hooks.
end note

note bottom of Order
  TURN RESTRICTIONS

  readyTurn records when the
  order becomes READY.

  Serving requires:
  currentTurn > readyTurn.

  Payment requires:
  currentTurn > readyToPayTurn
  on the Customer.
end note

note bottom of WaiterChoice
  ACTION-SPECIFIC TARGETS

  SeatChoice: customerId and tableId
  TakeOrderChoice: tableId
  ServeChoice: orderId
  WaitChoice: no target

  Avoids ambiguous generic targetId.
end note

note bottom of TurnProcessor
  STAFF LIMITS

  Waiter: maximum 1 action per turn.
  Chef: maximum 1 preparation unit per turn.
  Cashier: maximum 1 payment per turn.

  The exact end-of-turn processing
  order must follow the assignment.
end note
